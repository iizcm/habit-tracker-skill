# habit-tracker — Personal Habit & Routine Manager

**Status:** Placeholder - In Development

A comprehensive habit tracking and routine management system to build positive habits and break negative ones.

## Overview

**habit-tracker** helps users build and maintain positive habits, track progress over time, and develop consistent routines.

## Usage

### View habit dashboard
```bash
habit-tracker dashboard
```

### Log a habit
```bash
habit-tracker log <habit-name> <date>
```

### Check habit streaks
```bash
habit-tracker streaks
```

### Set habit reminders
```bash
habit-tracker reminders <habit-name>
```

## Best Practices

### Starting Habits

- **Begin with 1-2 habits** to build consistency
- **Start small** with easy habits
- **Track daily** immediately after completion
- **Use reminders** initially
- **Celebrate streaks** of any length

### Maintaining Habits

- **Identify triggers** for habit completion
- **Plan for disruptions** (travel, illness)
- **Use rewards** for completion
- **Review regularly** and adjust as needed
- **Build buffers** for missed days

### Breaking Bad Habits

- **Identify triggers** (what causes the bad habit)
- **Replace with good habits** (substitute behaviors)
- **Gradually reduce** bad habit frequency
- **Use accountability** methods
- **Celebrate progress** even small improvements

## Troubleshooting

### Habit Not Showing Progress
- Check date format
- Verify habit completion logging
- Clear cache if needed
- Restart application

### Streak Not Updating
- Ensure consistent logging
- Check for duplicate entries
- Verify date selection
- Try resetting streaks

### Apps Not Syncing
- Check internet connection
- Verify storage permissions
- Clear application data
- Reinstall if necessary
